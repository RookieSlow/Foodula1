Foodula1 is a Unity 2022.3.62f2 2D game where the player drives a food truck around an 85-node track using card-based movement. The core mechanic involves managing "Cold Storage" (heat) — driving too fast through corners generates penalties. Engine: Unity 2022.3.62f2, Language: C# 9.0, UI: uGUI + TextMesh Pro. Code lives in Assets/Scripts/. Three existing scripts: GameManager.cs (core controller), CardUI.cs (card interaction), TrackNode.cs (data class). Five speed-limited corners. See [[game-mechanics]] for details.
