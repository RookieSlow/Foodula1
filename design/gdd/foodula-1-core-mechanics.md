## 1. 核心游戏机制（HEAT 规则详细移植）

> 本章节详细描述所有需要实现的游戏逻辑，程序员可据此独立开发。

---

### 1.1 卡牌体系

游戏使用卡牌来驱动所有动作。每张卡牌是一个独立的数据对象。

#### 1.1.1 卡牌类型

| 卡牌类型 | 数值 | 来源 | 在手中的行为 | 特殊规则 |
|---|---|---|---|---|
| **速度牌（Speed）** | 1 / 2 / 3 / 4 | 初始牌组 | 打出 = 移动对应格数 | 必须打出（不能主动弃置） |
| **热量牌（Heat）** | 0 | 超速 / 引擎故障 / ±2换档 / 技能 | **不可打出**，纯粹占据手牌位 | 标准冷却按手牌→抽牌堆→弃牌堆；明确“从手牌”效果仍手牌限定 |
| **车队特技牌（Trick）** | 依车队而定 | 初始牌组（每队 2 攻 + 2 守） | 确认后立即发动并进入弃牌堆 | 每回合最多打出 1 张 |

#### 1.1.2 牌组构成

每位玩家拥有独立的牌组（Deck）、手牌（Hand）和弃牌堆（Discard Pile）。

**初始牌组（开局自动配置）：**

| 卡牌 | 数量 | 总计 |
|---|---|---|
| 速度牌 "1" | 3 张 | |
| 速度牌 "2" | 5 张 | |
| 速度牌 "3" | 3 张 | |
| 速度牌 "4" | 1 张 | |
| **速度牌小计** | | **12 张** |
| 热量牌 "0" | 3 张 | |
| 车队攻击特技牌 | 2 张 | |
| 车队防御特技牌 | 2 张 | |
| **初始牌组合计** | | **19 张** |

> 特技牌系统关闭时不加入上述 4 张特技牌，初始牌组仍为 15 张。系统开启时，
> 特技牌在开局抽牌前与速度牌、初始热量牌一起洗入牌组，不直接加入手牌。

#### 1.1.3 手牌管理规则

| 规则项 | 数值 | 说明 |
|---|---|---|
| 手牌上限 | 7 张 | 每回合结束时补至 7 张 |
| 回合开始自动抽牌 | 补至手牌上限 | 若牌组不足则洗入弃牌堆后继续抽 |
| 牌组抽空时 | 将弃牌堆洗牌 → 形成新牌组 | 速度牌、热量牌和特技牌均按所在弃牌堆一起循环 |
| 特技牌处理 | **逐张确认、立即结算** | 确认后从手牌进入弃牌堆并立即发动；仍受每回合 1 张限制 |
| 热量牌处理 | **不可打出** | 热量牌仅占手牌位，无法被选中打出；标准档位冷却量为 G1=3、G2=1，并按手牌→抽牌堆→弃牌堆处理 |
| 手牌补充 | 通常补至上限 | 特技或科技效果可以额外抽牌；普通补牌不会主动丢弃已有手牌 |

### 1.2 档位系统

档位是玩家每回合的"行动力"，决定了必须打出几张速度牌。

#### 1.2.1 档位规则

| 档位 | 每回合出牌数 | 说明 |
|---|---|---|
| 1 档 | 1 张 | 保守巡航，方便冷却热量 |
| 2 档 | 2 张 | 常规节奏 |
| 3 档 | 3 张 | 激进推进，热量积累快 |
| 4 档 | 4 张 | 极限冲刺，高风险高回报 |

**换档规则（HEAT 规则书）：**
- **±1 档**：免费，任意方向
- **±2 档**：支付 1 热力（从引擎抽 1 热力牌入弃牌堆），任意方向
- **每回合最多变 2 档**：不能从 4 档直接跳到 1 档
- **保持**：可以不换档，档位不变

> **冷却独立于换档**：冷却不再与降档绑定。冷却在步骤 5「反应」阶段根据当前档位执行：G1 = 冷却 3，G2 = 冷却 1，G3/G4 = 无冷却。

#### 1.2.2 引擎故障（手中速度牌不足）

若手中速度牌数量少于当前档位要求的出牌数（因为热量牌占据了手牌位），则：

1. 尽可能打出所有能打的速度牌
2. 不足的部分，每缺 1 张视为 **引擎故障**：从热量池抽取 1 张热量牌 → 放入弃牌堆
3. 本回合按实际打出的速度牌移动
4. **未打出的热量牌继续留在手牌中**——等待步骤 5 的标准冷却按手牌→抽牌堆→弃牌堆清除

### 1.3 完整回合流程

每个玩家的回合严格按以下 **9 个步骤** 顺序执行。数字版中，所有玩家先完成步骤 1~3（选档 + 出牌），然后再依次执行步骤 4~9。

#### 回合流程图

```
┌─────────────────────────────────────────────┐
│  PHASE A：所有玩家同步决策（输入阶段）         │
│                                               │
│  Step 1 — 换档                                │
│  ├─ 选择新档位（升 1 / 不变 / 降任意）           │
│  └─ 当前档位决定步骤 5 的冷却量（移除热量牌）       │
│                                               │
│  Step 2 — 抽牌                                │
│  └─ 从牌组抽至手牌上限 (7 张)                    │
│                                               │
│  Step 3 — 出牌                                │
│  ├─ 每次选择 1 张牌并点击“确认出牌”               │
│  ├─ 速度牌：移入本回合已打出区，累计移动力          │
│  ├─ 特技牌：立即发动并移入弃牌堆                   │
│  ├─ 无待确认牌时点击“结束出牌”完成本步骤            │
│  ├─ 速度牌不足 N 张时按缺口结算引擎故障（N = 档位）  │
│  └─ 所有玩家出牌完毕后进入结算阶段                │
├─────────────────────────────────────────────┤
│  PHASE B：按位置顺序依次结算（执行阶段）          │
│                                               │
│  Step 4 — 移动                                │
│  ├─ 总移动力 = 打出的速度牌数值之和               │
│  ├─ 每移动 1 格检查是否触发弯道判定               │
│  └─ 暂时标记最终位置（待尾流修正）                 │
│                                               │
│  Step 5 — 反应（冷却）                          │
│  ├─ G1 = 冷却 3, G2 = 冷却 1                     │
│  └─ 按手牌→抽牌堆→弃牌堆移除热量 → 归还引擎       │
│                                               │
│  Step 6 — 弯道判定                             │
│  ├─ 检查本回合移动路径上踩到的弯心                 │
│  ├─ 每个弯心：总移动力 vs 弯道限速                │
│  ├─ 超速部分 → 引擎支付热量（放入弃牌堆）          │
│  └─ 引擎不足 → 失控（见 1.8）                    │
│                                               │
│  Step 7 — 尾流判定                             │
│  ├─ 检查是否紧跟前车（距离 ≤ 1 格）               │
│  └─ 满足 → 额外 +2 移动（可再触发一次尾流判断）    │
│                                               │
│  Step 8 — 弃牌（可选）                          │
│  ├─ 可选择弃掉手中任意非热量牌                     │
│  └─ 弃掉的牌 → 弃牌堆                            │
│                                               │
│  Step 9 — 收尾                                 │
│  ├─ 将本回合打出的速度牌放入弃牌堆                 │
│  ├─ 已确认的特技牌无需再次处理（已即时进入弃牌堆）   │
│  ├─ 抽牌至 7 张                                  │
│  └─ 传递回合给下一个玩家                          │
└─────────────────────────────────────────────┘
```

### 1.4 移动与位置系统

#### 1.4.1 赛道数据模型

赛道由一系列连续的 **格子（Cell）** 组成，形成一条首尾相连的闭环。每个格子包含：

```json
{
  "schemaVersion": 1,
  "trackId": "monza_pasta",
  "gameCellCount": 50,
  "laps": 3,
  "hasPitLane": false,
  "weatherPool": ["sunny", "cloudy", "light_rain", "heavy_rain", "hot"],
  "cells": [
    {
      "index": 0,
      "type": "start_finish",
      "segmentId": "start_finish",
      "distanceMeters": 0,
      "position": { "x": 0.5, "y": 0.5 },
      "isApex": false
    },
    {
      "index": 8,
      "type": "corner",
      "segmentId": "ragu_rettifilo",
      "cornerId": "ragu_rettifilo",
      "cornerLevel": 3,
      "cornerLimit": 2,
      "distanceMeters": 926.88,
      "position": { "x": 0.62, "y": 0.48 },
      "isApex": true
    }
  ]
}
```

#### 1.4.2 弯道数据定义

| 弯道等级 | 限速值 | 典型弯道类型 | 视觉参考 |
|---|---|---|---|
| Lv 1（缓弯） | 4 | 高速弯、大弧度 | 银石 Copse |
| Lv 2（中弯） | 3 | 发卡弯前的中速弯 | 蒙扎 Parabolica |
| Lv 3（急弯） | 2 | 发卡弯、直角弯 | 摩纳哥 Grand Hotel |

弯道可以占据多个连续格子，但运行时只在移动路径跨过标记为 `isApex: true`
的弯心节点时判定；同一移动中的重复弯心会去重，不在普通入弯/出弯格重复惩罚。

#### 1.4.3 位置排序规则

同一格内可以有多辆车。当两辆车在同一格时，按以下优先级排序：
1. **本回合移动力更大** 的车排在前面
2. 若移动力相同，**先到达该格**（先结算）的车排在前面
3. 尾流判断只对"紧跟前车"（距离 ≤ 1 格）生效

### 1.5 弯道机制详解

这是游戏最核心的风险/回报节点。

#### 1.5.1 弯道判定规则（弯心判定）

每个弯道定义**一个弯心节点**（apex）。只有移动路径踩到弯心时才触发判定。

对于玩家本回合移动路径上踩到的**每一个弯心**：

1. 取本回合 **打出的速度牌数值总和** = `totalSpeed`
2. 取该弯道的限速值 = `cornerLimit`
3. 若 `totalSpeed ≤ cornerLimit` → 安全通过，无惩罚
4. 若 `totalSpeed > cornerLimit`：
   - `超速值 = totalSpeed - cornerLimit`
   - 从玩家引擎牌库抽取 `超速值` 张热量牌 → 放入弃牌堆
   - 这些热量牌将在牌组循环时进入手牌，形成延迟惩罚

> **为什么用弯心判定？** 如果一个弯道跨多节点，分两回合通过时不应被双重惩罚。弯心判定确保每个弯道每回合最多判定一次，且只在踩到弯道最急处时判定。

#### 1.5.2 引擎牌库不足

若引擎牌库中剩余热量牌不足，取走全部剩余热量牌。玩家可继续比赛，但后续需要抽牌时面临无牌可抽的风险。

#### 1.5.3 多弯道场景

若一次移动踩到了 **多个弯心**，每个弯道独立判定。例如：

> 玩家速度 = 5，踩到弯道 A（限速 3）和弯道 B（限速 2）  
> 弯道 A：超速 2 → 需支付 2 热量  
> 弯道 B：超速 3 → 需支付 3 热量  
> 总计需支付 5 热量

#### 1.5.4 车队操控属性对弯道的影响

赛车属性 **操控（Handling）** 的数值直接加成弯道限速：

```
有效限速 = 弯道原始限速 + 赛车操控加成
```

例如：意大利赛车操控 +2，在限速 3 的弯道中有效限速 = 5，以速度 5 通过不产生热量。

### 1.6 热量系统

热量是游戏的核心惩罚/限制机制。热量牌占据手牌位置，限制玩家每回合可用的速度牌数量。

#### 1.6.0 引擎耐久（Durability）

每辆赛车的 **耐久（Durability）** 属性定义了引擎热量牌库的**初始容量**。比赛开始时，引擎牌库中放置等于耐久值的热量牌。

| 耐久值 | 含义 |
|--------|------|
| 初始容量 | 引擎牌库中的热量牌数量 = 耐久值 |
| 被科技树提升后 | 容量同步增加（如耐久 7 → 8，引擎中多放 1 张热量牌） |
| 引擎抽空 | 当需要从引擎支付热量但引擎已空时 → 触发**失控**（见 1.8） |

> **设计说明**：耐久高（如德国 8、美国 8）意味着更大的热量缓冲池，可以承受更多弯道超速和激进操作后才触发失控。耐久低（如意大利 6、日本 6）意味着容错空间更小，需要更精准的热量管理。

#### 1.6.1 热量牌的生命周期（HEAT 原版规则）

```
引擎牌库（Engine Deck，每玩家独立）
    │
    │ 弯道超速 / 引擎故障 / ±2换档 → 从引擎支付热量牌
    ↓
弃牌堆（Discard Pile）
    │
    │ 牌组抽空时 → 将弃牌堆洗入牌组
    ↓
牌组（Draw Pile） → 抽牌 →
    │
手牌（Hand）
    │
    │ 热量牌在手牌中：不可打出、不可主动弃置、纯粹占位、堵塞出牌
    │
    │ 档位冷却（G1=3, G2=1, 步骤 5 反应阶段）
    ↓
引擎牌库（回到起点）
```

**三条硬规则：**

| 规则 | 说明 |
|------|------|
| **不可打出** | 玩家不能选择热量牌出牌。它与速度牌一同留在手牌中 |
| **不可主动弃置** | 无法通过任何操作主动丢弃手牌中的热量牌 |
| **标准自动冷却** | 步骤 5「反应」阶段按当前档位自动移除热量牌（G1=3, G2=1）；每次按手牌→抽牌堆→弃牌堆顺序冷却 |

#### 1.6.2 热量产生途径

| 途径 | 产生量 | 去向 |
|---|---|---|
| 弯道超速 | 每超 1 点 = 从引擎抽 1 张热量牌 | 弃牌堆 |
| 引擎故障（手中速度牌不足） | 每缺 1 张 = 从引擎抽 1 张热量牌 | 弃牌堆 |
| ±2 换档 | 支付 1 张热力牌 | 弃牌堆 |
| 技能/天气效果 | 依具体效果而定 | 弃牌堆 |

所有热量产生途径都从该玩家的引擎牌库抽牌放入弃牌堆——而非直接进手牌。热量牌通过牌组循环逐步进入手牌，形成延迟惩罚。

#### 1.6.3 冷却途径（将热量移回引擎）

| 途径 | 移除量 | 来源 | 去向 |
|---|---|---|---|
| 1 档冷却 | 步骤 5 自动移除 3 张 | **手牌→抽牌堆→弃牌堆** | → 引擎牌库 |
| 2 档冷却 | 步骤 5 自动移除 1 张 | **手牌→抽牌堆→弃牌堆** | → 引擎牌库 |
| 赛车属性"冷却效率"加成 | 冷却时额外移除 N 张 | **手牌→抽牌堆→弃牌堆** | → 引擎牌库 |
| 中国减速档 | Recover 内置冷却（3→2→1→0 连续递减链），不使用步骤 5 冷却 | **仅手牌** | → 引擎牌库 |
| 技能效果 | 依技能而定 | | |

> **设计说明**：冷却在步骤 5「反应」阶段根据档位执行，与换档操作解耦。G1 冷却量大（3），适合需要大量清热的场景；G2 冷却量小（1），适合轻量散热。

#### 1.6.4 过热机制

| 热量占比 | 效果 |
|---|---|
| 热量牌 ≥ 手牌的 50% | 屏幕边缘出现"过热警告"视觉效果 |
| 热量牌 ≥ 手牌的 70% | 设计目标：显示过热压力；当前运行时未接入“随机弃速度牌”副作用 |
| 手牌全部为热量牌 | 自动强制降至 1 档，利用 G1 冷却 3 逐步清除 |

### 1.7 尾流机制（Slipstream）

#### 1.7.1 触发条件

步骤 6 执行尾流判定：

1. 玩家移动结束后，检查与**正前方最近一辆车**的距离
2. 若距离 **≤ 1 格**（即紧贴前车后方或同一格排在后面），触发尾流
3. 额外获得 **+2 移动**（基础值，可被赛车属性/技能修正）

#### 1.7.2 链式尾流

尾流 +2 可能让你追上更前面的车，再次触发尾流判定。**每回合最多触发 2 次尾流**，防止无限链。

#### 1.7.3 不能尾流的情况

- 前方是队友且本队选择了"不尾流队友"的策略（策略选项待定）
- 前方无车（你是第一名）
- 前车距离 > 1 格

#### 1.7.4 车队尾流效率加成

赛车属性 **尾流效率（Slipstream）** 直接加成尾流移动距离：

```
尾流移动 = 基础值 2 + 赛车尾流效率加成
```

### 1.8 失控与爆缸机制（Spin Out & Blow-Up）

热量管理失败时触发**失控**，多次失控导致**爆缸**退赛。这是两个独立的机制层级。

#### 1.8.1 触发条件（失控）

任何需要从引擎牌库支付热量但引擎已空时触发**失控**：

| 触发场景 | 说明 |
|------|------|
| 弯心超速 | 总速度 > 弯道限速，引擎不够付差额 |
| 引擎故障 | 速度牌不够档位，引擎不够付缺额 |
| ±2 换档 | 引擎不够支付 1 热力 |

#### 1.8.2 失控处理流程

```
1. 爆缸计数器 +1（显示 ⚠ ×N/3）
2. 回退位置：弯心超速 → 弯心前一格；引擎故障/±2换档 → 原地
3. 回收全部热量牌 → 引擎牌库（重新点火）
   · 手牌、牌组、弃牌堆中的所有热量牌 → 移除 → 归还引擎
4. 强制降至 1 档
5. 跳过下一回合
6. 爆缸计数器 = 3 → 引擎爆缸，强制退赛（DNF）
```

#### 1.8.3 爆缸计数器

| 计数器值 | 状态 | 效果 |
|----------|------|------|
| 0 | 🟢 正常 | 无 |
| 1 | 🟡 警告 | UI 显示 ⚠×1 |
| 2 | 🟠 危险 | UI 显示 ⚠×2，屏幕边缘闪烁 |
| 3 | 🔴 爆缸 | **强制退赛**（DNF），排名计为最后 |

> **设计说明**：耐久和爆缸计数器是两个独立概念。耐久决定引擎容量（热量缓冲池大小），爆缸计数器决定容错次数（可以失控几次才退赛）。耐久高的车队（德/美 8）更不容易触发失控，但一旦失控，大家都在同一条 3 次就爆缸的起跑线上。比赛全程爆缸计数器不清零——每一次失控都是永久代价。

#### 1.8.4 跳过回合

被跳过的回合中，玩家：
- 不能换档
- 不抽牌
- 不出牌
- 不移动

### 1.9 赛道与圈数

#### 1.9.1 圈数规则

| 参数 | 建议值 | 说明 |
|---|---|---|
| 标准比赛圈数 | 2~3 圈 | 短赛道 3 圈，长赛道 2 圈 |
| 单圈长度 | 以 JSON 为准 | 当前官方可选赛道为 42/50/55/60/62/142/219 格，比赛为 1~3 圈 |
| 通过起点线 | 圈数 +1 | 自动记录，UI 显示 "Lap 2/3" |

#### 1.9.2 通过起点/终点线

- 由 `type: "start_finish"` 标记运行时起终点；它不要求位于 `index: 0`
- 当玩家正向跨过运行时起终点节点时，圈数 +1；从末尾绕回或从任意节点跨过该标记均按同一规则处理
- 最后一圈通过终点线 → 比赛结束，记录名次

### 1.10 比赛结束与排名

#### 1.10.1 结束条件

1. **有人冲线**：任意玩家完成最后一圈通过终点线 → 该玩家锁定第 1 名
2. **其余玩家**：当前回合继续进行，直到所有非失控玩家完成当前回合
3. **排名规则**：先按圈数排序，同圈按位置排序，同位置按本回合速度排序

#### 1.10.2 锦标赛积分

| 名次 | 1st | 2nd | 3rd | 4th | 5th | 6th |
|---|---|---|---|---|---|---|
| 积分 | 9 | 6 | 4 | 3 | 2 | 1 |

### 1.11 数字版特有的自动化处理
