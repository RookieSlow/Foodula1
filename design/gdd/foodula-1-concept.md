## 一、游戏概述

### 1.1 一句话描述

一款以"各国美食化为赛车"为主题的回合制策略竞速游戏，改编自 HEAT 桌游核心机制，玩家管理热量、档位与手牌，在赛道上一决高下。

### 1.2 核心体验（Player Fantasy）

玩家扮演车队经理兼车手，驾驶由本国代表性美食魔改而成的赛车，在世界各地的赛道上策略竞速。每一次出牌都是热量与速度的博弈——推得太猛会"烧焦"，过于保守则被对手甩开。

### 1.3 与 HEAT 原版的核心差异

| 维度 | HEAT 原版 | Foodula 1 |
|---|---|---|
| 主题 | 1960s F1 方程式 | 美食赛车（Food Racing） |
| 车队 | 无车队系统，仅颜色区分 | 6 支国家美食车队，各有特性 |
| 车手 | 无 | 车手系统 + 技能树 |
| 赛车 | 统一模板 | 各国美食魔改造型 + 差异化性能 |
| 成长 | 锦标赛升级卡牌 | 技能树解锁 + 车手养成 |
| 赛道 | 固定赛道 | 主题赛道 + 天气/路况效果 |
| 卡牌升级 | 锦标赛间升级 | 保留 + 技能树关联升级 |

### 1.4 设计支柱

1. **策略 > 运气**：胜负取决于档位选择、热量管理和出牌时机，而非抽牌运气
2. **推拉博弈**：每一次加速都是一次风险决策——快一步可能赢，也可能烧焦出局
3. **差异化但不失衡**：每支车队有明显的风格差异，但没有绝对的最强
4. **易上手难精通**：基础规则 10 分钟学会，高手博弈有深度

### 1.5 世界观设定

> **"在这个世界，速度与厨艺是同一件事。"**

Foodula 1 的世界是一个与我们高度相似的平行宇宙——地理、国家、文化几乎一致，但有一个根本性的差异：**赛车运动的本质不是机械工程，而是烹饪艺术。** 被我们称为"Formula 1"的赛事在这里叫做 Foodula 1（美食方程式大奖赛），是全球最顶级的赛事。

#### 三条世界法则

| 法则 | 说明 |
|---|---|
| **食材即引擎** | 赛车由各国代表性食材"活化"而成——食物本身就是赛车，不是食品造型的机械 |
| **热量即速度也是代价** | 引擎热度 = 烹饪火候。推太猛→"烧焦"；太保守→"夹生" |
| **车队即厨房** | 车手 = 厨师 + 车手双重身份。技术总监 = "主厨（Chef）" |

#### 赛事体系

国际美食赛车联合会（IGRA）主办的 6 站世界锦标赛，6 支国家队争夺**金锅奖杯（Golden Wok Trophy）**。积分制：9-6-4-3-2-1。

## 二、核心游戏机制（摘要）

> 📄 完整规则详见 **`foodula-1-core-mechanics.md`**

Foodula 1 是一款**卡牌驱动的回合制策略竞速游戏**。当前回合按 9 个步骤处理：换档 → 抽牌 → 出牌 → 移动 → 反应冷却 → 弯道判定 → 尾流判定 → 弃牌 → 收尾。

### 核心系统速览

| 系统 | 一句话说明 |
|---|---|
| **卡牌体系** | 速度牌（1~4）驱动移动；热量牌（0）不可打出、仅占手牌位；车队专属牌替换压力牌 |
| **档位系统** | 1~4 档决定每回合出牌数。±1 档免费，±2 档支付 1 热力。冷却独立于换档（G1=3, G2=1） |
| **热量系统** | 弯道超速/±2换档/引擎故障支付热量。热量牌从独立引擎池进入手牌或弃牌堆，只能通过冷却回引擎 |
| **弯道机制** | 每个弯道有 Lv1（限速 4）/ Lv2（限速 3）/ Lv3（限速 2）。总移动力超过限速 → 支付热量牌 |
| **尾流机制** | 紧跟前方赛车（≤1 格）获得 +2 额外移动，每回合最多 2 次 |
| **失控与爆缸** | 引擎热不足支付时触发失控：回退位置 + 回收全部热量 + 爆缸计数器 +1 + 强制降 1 档 + 跳过下回合。计数器到 3 → 引擎爆缸，强制退赛 |

### 回合流程

```
PHASE A（同步决策）：换档 → 抽牌 → 出牌
PHASE B（依次结算）：移动 → 弯道判定 → 尾流判定 → 收尾
```

### 关键数值
- 手牌上限：7 张
- 普通初始牌组：基础 12 张速度牌；启用特技牌时为 16 张。热量牌不属于普通牌组
- 标准比赛：3 圈

## 七、游戏模式

### 7.1 模式总览

| 模式 | 说明 | 玩家人数 | AI | Demo 是否实现 |
|---|---|---|---|---|
| **快速比赛** | 选赛道、选车、直接开跑，单场 AI 对战 | 1~6 | 是 | ✅ 核心验证 |
| **计时赛** | 独自刷圈速，无热量限制，无对手 | 单人 | 否 | ❌ 设计目标，当前菜单未作为独立模式验证 |
| **锦标赛** | 6 站积分赛，累计积分决定总冠军 | 1~6 | 是 | ❌ 后续 |
| **生涯模式** | 从菜鸟到传奇，解锁技能树 + 升级卡牌 | 单人 | 是 | ❌ 后续 |
| **本地多人** | 热座模式（同一设备交替操作） | 2~6 | 否 | ❌ 后续 |
| **线上对战** | 匹配/好友对战（阶段同步方案 C） | 2~6 | 否 | ❌ 后续 |

### 7.2 多人模式方案（已定稿，Demo 不实现）

采用**阶段同步（Phased Sync）**方案：

- **PHASE A（决策）异步**：各玩家随时提交选档 + 出牌
- **PHASE B（结算）服务器统一执行**：最后一人提交后自动结算移动
- **超时处理**：超时未提交 → 系统自动选保守 2 档 + 随机出牌；连续 2 回合超时 → AI 接管
- **时效可选**：快速模式 1h / 常规 6h / 休闲 24h

## 八、AI 系统框架

> 📄 完整设计详见 **`foodula-1-ai.md`**

Demo 阶段采用**简单行为树**架构，4 个优先级节点：

| 优先级 | 节点 | 决策 |
|---|---|---|
| P1 | 生存检查 | 热量 ≥ 70% → 降到 1 档全力冷却；手牌不足 → 降档 |
| P2 | 弯道策略 | 预判前方弯道限速，必要时降档/保守出牌 |
| P3 | 尾流利用 | 前方 ≤ 2 格有对手 → 精确匹配距离触发尾流 |
| P4 | 常规推进 | 热量低安全 → 升档冲刺；正常 → 保持 + 随机注入变化 |

中国车队使用独立的 2 档 AI 逻辑（Go/Recover 连续规则）；电池阈值驱动的 AI 进站决策仍是后续设计。

| 难度（后续扩展） | 热量管理 | 尾流利用 | 出牌优化 |
|---|---|---|---|
| 🟢 简单 | 保守（>30% 冷却） | 随机 | 随机出可用的牌 |
| 🟡 中等 | 适中（>50% 冷却） | 有意识利用 | 按速度降序出牌 |
| 🔴 困难 | 激进（>70% 冷却） | 最大利用 | 计算最优出牌组合 |

## 九、术语表

| 中文 | 英文 / 代码标识 | 定义 |
|---|---|---|
| 档位 | Gear | 1~4 档，决定每回合出牌数量 |
| 速度牌 | Speed Card | 数值 1~4 的卡牌，决定移动格数 |
| 热量牌 | Heat Card | 数值 0，惩罚/资源牌，占据手牌位 |
| 车队专属特技牌 | Team Trick Card | 每队 4 张（2 攻 2 守）的特殊效果牌，不占档位，每回合限 1。注意与车手特技区分 |
| 升级牌 | Upgrade Card | 锦标赛间获取的高级卡牌（后续设计，当前阶段不可用） |
| 牌组 | Deck | 玩家未抽取的卡牌集合 |
| 弃牌堆 | Discard Pile | 使用过的卡牌 |
| 引擎牌库 | Engine Deck | 每玩家独立的热量牌库。初始容量 = 耐久值。支付热量时从此取出，进入手牌或弃牌堆 |
| 尾流 | Slipstream | 紧跟前方赛车获得的额外移动加成（基础 +2） |
| 失控 | Spin Out | 引擎不足以支付热量需求时触发。爆缸计数器 +1，回收全部热量，降 1 档，跳过下回合 |
| 爆缸 | Blow-Up | 爆缸计数器达到 3 → 引擎爆缸，强制退赛（DNF） |
| 冷却 | Cooldown | 步骤 5「反应」阶段按手牌→抽牌堆→弃牌堆冷却热量：G1=3, G2=1。中国 Recover 使用 3→2→1→0 的手牌限定内置冷却，不使用步骤 5 |
| 弯道限速 | Corner Limit | 通过弯心允许的最大总速度值 |
| 操控 | Handling | 赛车属性，加成弯道限速 |
| 特技 | Signature Move | 车手的独有技能，每场限用。与车队专属特技牌是不同的系统 |
| 研发点数 | RP | 比赛按名次获得，按车队独立追踪，用于解锁科技树节点 |
| 地标 | Landmark | 美国车队专属机制——赛道上的特殊标记点，美国科技树围绕地标运作 |
