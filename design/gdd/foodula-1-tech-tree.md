## 〇、科技树框架

### 结构

```
L1 通用层 (5 选 3) → L1 专属科技
    ↓
L2 通用层 (5 选 3) → L2 专属科技
    ↓
L3 大师层 (无需通用前置) → L3 专属科技
```

每支车队在 L1/L2/L3 各有一个专属科技。通用科技所有车队共享。

### 通用科技

#### L1 通用（5 选 3）

| # | 名称 | 效果 |
|---|------|------|
| 1 | 强化散热片 | 冷却时额外移除 1 张热量 |
| 2 | 轻量化底盘 | 每回合速度牌总和 +1（仅直道） |
| 3 | 赛道记忆 | 弯心限速 +1 |
| 4 | 扩容油箱 | 引擎上限 +1 |
| 5 | 尾流优化 | 尾流距离从 1 格放宽到 2 格 |

#### L2 通用（5 选 3，覆盖 L1 同类型）

| # | 名称 | 效果 |
|---|------|------|
| 1 | 双风扇散热 | 冷却时额外移除 2 张热量（覆盖 L1 #1） |
| 2 | 碳纤维车身 | 每回合速度牌总和 +2（覆盖 L1 #2） |
| 3 | 极限操控 | 弯心限速 +2（覆盖 L1 #3） |
| 4 | 备用油箱 | 引擎上限 +2（覆盖 L1 #4） |
| 5 | 真空尾流 | 尾流 +2 → +3（覆盖 L1 #5） |

> **叠加规则**: L2 覆盖同类型 L1，不叠加。不同类型各自生效。

## 一、🇬🇧 英国 — 炸鱼薯条车队

**核心机制 — Royal Engineer**: 升至 L2 时，可从其他任意车队额外自选 1 个 L1 专属科技。

### L1 — 炸鱼薯条 `Fish & Chips`

> *"渔夫的坚韧——高热量、扛饿，只要还有一口气就不会翻船。"*

每场限 1 次。当需要支付热量但引擎不足时，忽略这次热量判定，并从一处移回 1 张热量牌至引擎（优先级：手牌 → 牌组 → 弃牌堆，找到即停）。若三处均无热量牌，仅忽略判定。

### L2 — 全套英式早餐 `Full English`

> *"培根、香肠、鸡蛋、豆子、蘑菇——少一样都不叫全套。"*

手牌中同时含有热量牌、速度牌、特技牌时，本回合获得 1 点临时热力 + 尾流距离 +1。不消耗手牌。

### L3 — 日不落引擎 `The Sun Never Sets`

> *"太阳始终照耀帝国的疆土。"*

获得当前赛道所属国家车队的 L2 和 L3 专属科技。英国主场时，额外触发一次「全套英式早餐」效果。

## 二、🇩🇪 德国 — 啤酒黑面包车队

### L1 — 黑啤酒燃料 `Schwarzbier Fuel`

> *"一口黑啤，一脚油门。"*

任意时刻，将引擎中 1 张热量牌支付到弃牌堆，前进 2 格。

### L2 — 香肠拼盘悬架 `Wurstplatte Suspension`

> *"香肠悬架，吃更多路肩。"*

出弯后，赛车前进 1 格且不参与弯心限速判定。（实现：先判定超速，再 +1。）

### L3 — 纽博格林限定烤肉 `Nürburgring Grill-Spezial`

> *"北环的烤肉摊——熏够烟火气的车手，什么都不怕。"*

每场 1 次。本回合从引擎支付的所有热量牌，在回合结束时从弃牌堆自动冷却回引擎。与 L1 联动可爆发超高单回合规避。

## 三、🇮🇹 意大利 — 意面披萨车队

### L1 — 薄底手拍披萨底盘 `Pizza Sottile`

> *"意式薄底——轻、脆、贴地飞行。"*

通用科技中「轻量化」分类的效果翻倍。

### L2 — 千层面复合单体壳 `Lasagna Monoscocca`

> *"千层面一层一层叠起来——更快、更硬、更多汁。"*

失控计数器上限 +1，手牌上限 +1，引擎容量 +1。

### L3 — 红色跃马认证 `Cavallino Rampante`

> *"法拉利红——赛车界没有比这更有吸引力的颜色。"*

- 签约车手时吸引力大幅提升；获得冠军时经济收益 ×1.5
- 蒙扎主场/意大利车手：上述效果再 ×1.5
- **[Demo 占位]** 蒙扎主场时，失控计数器上限额外 +1

## 四、🇺🇸 美国 — 汉堡烤肉车队

**核心机制 — 地标系统**：赛道发车格 + 66号公路服务区（位置 = ⌊赛道总格数 / 2⌋）各部署一个地标。每个美国玩家的地标独立追踪。所有美国专属科技围绕地标发挥作用。

### L1 — 得来速 `Drive-Thru`

> *"快餐不用停车——点了就走。"*

当你**正向经过**地标所在格时，本次行动结束后额外前进 **1 格**。

### L2 — 烟熏BBQ `Smoked BBQ`

> *"低慢烤，熏到后车睁不开眼。"*

当你位于地标 **±5 格**范围内时，获得 **BBQ Buff**：

| 效果 | 说明 |
|------|------|
| 🔥 热牌即速度 | 手中的热量牌可视为速度 2 的速度牌打出 |
| 💨 烟幕 | 你身后的赛车不享受尾流 bonus |
| ⛽ 大缸径 | 引擎容量上限 +2 |

若两个地标的 BBQ 区重叠，效果**不叠加**（同一 Buff）。

### L3 — 母亲之路 `The Mother Road`

> *"从风城到天使之城。繁荣、衰败、复兴——路即美国。"*

每个地标独立追踪**经过次数**（正向通过 +1）：

| 经过次数 | 阶段 | 效果 |
|----------|------|------|
| 第 1-2 次 | 🌟 繁荣 | 自动触发：免费冷却 **2 张**热量牌 |
| 第 3 次起 | 🏚️ 衰败 | 自动触发：可选从引擎支付 **1 张**热量牌修复地标（引擎无热则跳过） |

**复兴条件**：累计修复次数达到赛程所需：

| 赛程圈数 | 所需修复 |
|----------|----------|
| ≤ 3 圈（短赛） | 1 次 |
| 4-5 圈（标准） | 2 次 |
| ≥ 6 圈（长赛） | 3 次 |

**复兴后 🏛️**：此后经过该地标时，**每场对局限 1 次**——将手牌中所有热量牌洗回引擎，每洗回 1 张 → 前进 1 格。

| 追踪项 | 每地标所需 |
|--------|-----------|
| 经过次数 | 1 个整型计数器（阶段自动推导） |
| 大招已用 | 1 个 bool |

### 三者联动

```
L1 得来速   → 每次经过地标 +1 格，鼓励频繁绕圈

L2 烟熏BBQ → BBQ 区内热牌变速度 2 + 引擎+2 提升储热上限
            → 地标区变成 "美国领地"（无尾流 → 防守壁垒）

L3 母亲之路 → 繁荣期（冷却 2 × 2 次）→ 保温控温
            → 衰败期（付热修路）→ 烧热推进复兴
            → 复兴后终盘大招 → 手牌热全部变现为位移
```

> **平衡性备注**：上面数值为设计初稿，实际测试后需大幅调整以达到平衡。

### 与已有四国对比

| 国家 | 核心机制 | 操作风格 |
|------|----------|----------|
| 🇬🇧 UK | 偷学他国 L1（Royal Engineer） | 适应/灵活 |
| 🇩🇪 DE | 热量换位移（1 热 → 2 格） | 激进效率 |
| 🇮🇹 IT | 轻量翻倍 + 经济系统 | 精巧长线 |
| 🇺🇸 US | **地标空间控制 + 叙事弧线** | 领地防守/终盘爆发 |

## 五、🇨🇳 中国 — 茶点车队

**核心机制 — 热量循环**：中国队不把热量视为敌人，而是呼吸节奏的一部分。热量在引擎和手牌之间循环流动，冷热交替即是速度。

### L1 — 阴阳茶 `Yin-Yang Tea`

> *"热即是力，凉即是行。一盏茶的功夫，冷热周而复始。"*

每回合结束时，根据手牌状态触发：

| 手牌状态 | 效果 |
|----------|------|
| 无热量牌（阴） | 可从引擎支付 **1 张**热量牌 → 行动结束后前进 **1 格** |
| 有热量牌（阳） | 自动冷却 **1 张**热量牌（引擎 → 弃牌堆） |

> L1 判定独立于 L2，始终生效。

**典型节奏**（未受伤情况）：
```
T1: 手牌干净 → 阴：付热+1格 → 手牌有热
T2: 手牌有热 → 阳：自动冷却1 → 手牌干净
T3: 同 T1 ……
```

---

### L2 — 促销！早茶拼盘送续杯 `Dim Sum Combo`

> *"虾饺、烧卖、叉烧包——搭啱顺序，送多一壶。边推车边饮茶！"*

本回合内，若按以下顺序出牌：

```
① 特技牌 → ② 速度牌 → ③ 支付热量牌
```

则额外触发一次**阴阳茶**效果（根据当前手牌状态，与 L1 独立堆叠）。

| 条件 | 说明 |
|------|------|
| 三牌缺一 | L2 不触发，但不影响 L1 正常运作 |
| 顺序严格 | ①→②→③ 必须按序，不可调换 |

> **上限场景**：阴状态 → L1 付热 + L2 再付热 = 一回合 +2 格。代价：引擎双倍耗热。

---

### L3 — 筋斗云型 ATTACK `Somersault Cloud Attack`

> *"一个筋斗十万八千里——古老的速度信仰，刻进卡牌里。"*

将你的 **ATTACK 特技牌** 永久升级为 **筋斗云型**，每张升级后的 ATTACK 牌获得：

| 升级效果 | 说明 |
|----------|------|
| 🚀 尾流 +2 | 本回合尾流加速额外 +2 |
| 🏎️ 弯心 +1 | 本回合过弯限速 +1 |

> ATTACK 牌保留原有基础效果，筋斗云效果在此基础上叠加。
>
> **注**：ATTACK 特技牌的具体效果将在「车队专属特技牌设计」阶段统一定义。

---

### 三者联动

```
L1 阴阳茶    → 热循环节拍器：冷热交替，稳定产出位移 + 控温
L2 早茶拼盘  → 规划三连击，一回合打出两次阴阳茶
L3 筋斗云    → ATTACK 牌质变：跟车 + 过弯 T0 级增强
```

**玩法弧线**：日常热循环维稳 → 关键时刻凑三连爆发 → 终盘筋斗云 ATTACK 无视赛道限制。

## 六、🇯🇵 日本 — 寿司拉面车队

**核心机制 — 精准 + 开局构筑 + 以下克上**：职人精神贯穿三层——L1 追求一刀入魂的精准，L2 开局选择流派，L3 在最劣势时爆发转子引擎的全部潜能。

### L1 — 寿司一握 `Nigiri`

> *"舍利与种，一刀一握。不多一分，不少一毫。"*

过弯时，若你的通过速度**恰好等于**弯心限速值，则出弯结束后额外前进 **2 格**。

> 触发条件严格——速度牌总和必须精确匹配限速值。高了超速，低了浪费。

---

### L2 — 汤底定味 `Broth Selection`

> *"博多浓郁，东京清爽，札幌浓醇，函馆澄澈。选你的流派。"*

**游戏开始时**，从以下四张流派特技牌中选择 **1 张**置入手牌：

| 流派特技 | 加成方向 | 全局被动效果 |
|----------|----------|-------------|
| 🍖 豚骨 | 直道 | 直道（非弯心格）位移 +1 |
| 🥢 酱油 | 弯道 | 弯心限速 +1 |
| ⬜ 味噌 | 尾流 | 尾流加速额外 +1 |
| 🧂 盐味 | 冷却 | 每回合结束时冷却 1 张 |

> 开局打出一次（不消耗手牌算、不计入出牌数），获得该流派的**全局被动 Buff**，持续整场。后续不再需要打出。

---

### L3 — 番狂わせ `Bankuruwase`

> *"大冷门。787B 在勒芒的橙色闪电。转子转起来——以下克上。"* 🔺

**回合开始时**判定：若你当前排名为**倒数第一或倒数第二**，触发 🔺 转子引擎：

| 属性 | 说明 |
|------|------|
| 持续时间 | **连续 3 回合**（转子三弧边），到期自动结束 |
| 效果 ① | 每回合引擎冷却 **1 张**热量牌 |
| 效果 ② | 暂时获得 L2 **全部四种**流派 Buff（豚骨 + 酱油 + 味噌 + 盐味） |
| 中断规则 | 3 回合为连续计时，即使中途排名回升到第三名以上也不会暂停 |

> 🔺 转子三角形象征 R26B 四转子引擎的转子弧边——三个弧边各代表一个爆发回合。触发特效建议使用三角旋转动画。

---

### 三者联动

```
L1 寿司一握   → 精准操作奖励（限速 = 速度 → +2 格）

L2 汤底定味   → 开局选择一项全局被动，定义整场打法
              → 豚骨：直道碾压流
              → 酱油：弯道精准流（与 L1 叠加：限速+1 更易触发一握）
              → 味噌：跟车尾流流
              → 盐味：控温保守流

L3 番狂わせ   → 落后时 3 回合全流派解放
              → L2 单选时是职人，L3 触发时是神
              → 酱油流触发 L3 → 限速+1 + 尾流+1 + 直道+1 + 冷却+1
              → L1 更容易触发（限速+1 扩大了匹配窗口）
```

**玩法弧线**：开局选流派定风格 → 中期精操一握赚位移 → 落后时转子觉醒 3 回合全流派翻盘。
