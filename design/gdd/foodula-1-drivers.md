## 一、车手系统

### 1.1 车手属性

| 属性 | 代码标识 | 说明 |
|---|---|---|
| **天赋（Talent）** | `talent` | 影响 XP 获取速率（1.0x / 1.2x / 1.5x） |
| **经验（Experience）** | `xp` | 比赛获得，用于解锁技能节点 |
| **等级（Level）** | `level` | XP 累积到阈值自动升级 |
| **风格（Style）** | `style` | Aggressive / Balanced / Technical → 设计目标为影响同系技能效果 +10%；当前运行时仅保存描述 |
| **特技（Signature）** | `signature` | 每场限用 1~2 次的独特技能 |

### 1.2 XP 与升级

车手的被动技能和主动特技随等级逐步解锁和提升。

| 等级 | 累计 XP 需求 | 被动技能 | 主动特技 |
|---|---|---|---|
| Lv1 | 0 | 不可用 | 不可用 |
| Lv2 | 100 | ⭐ Tier 1 解锁 | — |
| Lv3 | 250 | — | ⚡ Tier 1 解锁（每场 1 次） |
| Lv4 | 500 | ⭐ Tier 2 升级 | — |
| Lv5 | 1000 | — | ⚡ Tier 2 升级 |
| Lv6 | 2000 | ⭐ Tier 3 升级 | — |
| Lv7 | 4000 | — | ⚡ Tier 3 升级（每场 2 次） |

**每场比赛 XP 获取：**
- 完成比赛：+50（基础）
- 锦标赛名次加成：1st +100, 2nd +60, 3rd +30, 其余 +10
- 天赋（Talent）加成：基础值 × talent 倍率
- 英国车队额外 +20% XP（皇家工程师加成）

> 车队科技树（第五节）的节点解锁使用独立的"科技点数"，不与车手 XP 共用。

### 1.3 车手技能体系

每位车手拥有 **1 个被动技能 + 1 个主动特技**，随等级提升逐渐解锁并提高数值。这取代了传统的"独立技能树"——车手的个性通过双技能体现，而通用的养成深度由车队科技树（第五节）提供。

**技能解锁节奏：**

| 等级 | XP 累计 | 解锁内容 |
|---|---|---|
| Lv1 | 0 | 基础属性，被动技能不可用，主动特技不可用 |
| Lv2 | 100 | ⭐ 被动技能 Tier 1 解锁 |
| Lv3 | 250 | ⚡ 主动特技 Tier 1 解锁（每场 1 次） |
| Lv4 | 500 | ⭐ 被动技能 Tier 2 升级 |
| Lv5 | 1000 | ⚡ 主动特技 Tier 2 升级 |
| Lv6 | 2000 | ⭐ 被动技能 Tier 3 升级 |
| Lv7 | 4000 | ⚡ 主动特技 Tier 3 升级（每场 2 次） |

> 英国车队特殊规则：被动技能效果 ×1.25（皇家工程师加成），主动特技使用次数 +1。

**主动特技运行时约束：**

- 仅能在本回合档位确认前主动发动；按钮必须显示等级锁定、条件不足、持续中和剩余次数。
- 自由赛事按车手 ID 保存 XP，下一场初始化时回读；教程不读写 XP，生涯继续使用其隔离结算规则。
- 主动效果由 `DriverSkillRules` 和 `DriverSkillRuntimeState` 统一结算，比赛日志记录 `[DRIVER_SKILL]`。
- 已接入的被动效果在回合开始、抽牌、支付热量、弯道和回合结束事件中自动结算；被动效果不显示额外按钮。
- 曼塞尔、舒马赫、维特尔、周、马的旧描述已修订为可验证效果；其他七个被动仍保留为配置描述，待后续逐项接入。
