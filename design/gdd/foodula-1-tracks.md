## 〇、过弯判定逻辑（已定稿 — 弯心判定）

### 判定方式：弯心判定（Apex Judging）

每个弯道定义**一个弯心节点（apex）**——弯道最急的那一点。只有移动路径踩到弯心时才触发超速判定。

**规则：**
```
本回合移动路径上的所有节点 → 检查每个节点是否是弯心（`isApex: true`）
→ 对每个踩到的弯心：
    → 取 totalSpeed（本回合打出的速度牌总和）
    → 取有效限速 = cornerLimit + 赛车操控加成
    → 若 totalSpeed > 有效限速：
        → 超速值 = totalSpeed - 有效限速
        → 从引擎牌库支付等量热量牌放入弃牌堆
```

**为什么用弯心判定：**
- 分两回合过一个弯 → 只在踩到弯心的那回合判定一次，不重复惩罚
- 弯心的位置设计决定了战术深度——你可以选择在弯心前刹车（分两回合），也可以全力冲过弯心
- HEAT 桌游原版中弯道就是一个判定点，弯心判定更接近原版体验

**实现要点：**
- 赛道数据中只有弯心节点标注 `cornerId`、`cornerLimit`、`isApex`
- 弯道段的其他节点（入弯/出弯）不标注弯道数据，视为普通直道
- 判定逻辑遍历路径节点，遇到 `isApex: true` 的节点就触发判定，并按 cornerId 去重

## 一、设计方法论：从真实赛道到游戏格子

### 1.1 转化规则

游戏使用格子系统（Cells），真实赛道需要抽象为"直道格 + 弯道格"的线性序列。转化遵循以下原则：

| 原则 | 说明 |
|---|---|
| **保留弯道节奏** | 弯道类型和顺序忠实于真实赛道——发卡弯还是发卡弯，高速弯还是高速弯 |
| **比例缩放** | 真实 5~6km → 游戏 45~65 格，缩放比约 1:100 |
| **美食化命名** | 弯道名称保留原名 + 添加食物前缀；赛道名使用美食主题 |
| **简化复杂序列** | F1 的 5 连 S 弯 → 游戏中可简化为 3~4 格的一段连续弯道区 |
| **保留标志性地标** | 每个赛道保留 1~2 个最具辨识度的弯道组合（如铃鹿的 130R、银石的 Maggotts-Becketts） |

### 1.2 弯道等级映射

| 游戏弯道等级 | 限速值 | 真实弯道对应 | 典型弯道 |
|---|---|---|---|
| **Lv 1（全油假弯）** | 6 | 现代赛车可全油或仅极轻微收油，战术上接近直道 | Abbey, Copse, Curva Grande, 130R, 200R |
| **Lv 1（高速弯）** | 5 | 高速通过但仍需要明确走线或轻微减速 | Maggotts/Chapel、Porsche Curves、Tertre Rouge |
| **Lv 1（常规快弯）** | 4 | 明显高速弯，需要收油或短制动 | Parabolica、Ascari、Dunlop |
| **Lv 2（中弯）** | 3 | 中速弯，需轻刹或稳定控速 | Stowe, Lesmo, Spoon, 大部分常规弯 |
| **Lv 3（急弯）** | 2 | 低速弯/发卡弯/减速弯，需重刹 | The Loop, 发卡弯, Rettifilo Chicane, 大部分 Chicane |

### 1.3 网格类型定义

| 格子类型 | 代码标识 | 说明 |
|---|---|---|
| `start_finish` | 起点/终点线 | 每圈经过一次，圈数 +1 |
| `straight` | 直道 | 无弯道判定，美国车/德国车可能获得加成 |
| `corner` | 弯道（单格） | 经过时进行弯道判定 |
| `corner_chain` | 连续弯道区 | 多个连续弯道格共享同一弯道名，每格独立判定 |
| `pit_entry` | 维修区入口 | 有维修区赛道上的进站路径；选择窗口在入口前 1–10 格 |
| `pit_exit` | 维修区出口 | 出站回到赛道的位置 |
| `special` | 特殊装饰格 | 无机械效果，仅用于视觉/UI 展示（如铃鹿十字交叉的筷子雕塑/隧道） |

### 2.4 🇺🇸 印第安纳波利斯汉堡赛道（Indianapolis Burger Circuit）

> **原型**：Indianapolis Motor Speedway Oval（美国，采用椭圆赛道而非 F1 路线的设计理念）
> **真实数据**：4.023km · 4 弯 · 逆时针 · 纯粹椭圆  
> **游戏总格数**：42 格  
> **标志性段落**：四个完全相同的高速倾斜弯；四条车道由内向外限速逐级提高
> **美食主题**：美式汉堡与可乐——维修区是汽车餐厅（Drive-thru），颁奖台是一张野餐桌

- **意大利车队的第二主场**：Lv2 弯道密集（13 格）+ 阴阳弯渐变特性，操控价值极高
- **美国车队的矛盾赛道**：直道极长（主场级优势）但阴阳弯和安亭弯的 Lv3 段惩罚也很重
