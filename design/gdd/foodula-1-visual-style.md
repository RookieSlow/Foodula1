# 《Foodula 1》视觉风格规范

> **文档状态**：视觉方向定稿 · 可指导美术制作  
> **关联文档**：`foodula-1-concept.md`（主 GDD）、`foodula-1-tracks.md`（赛道设计）  
> **创建日期**：2026-07-13  
> **设计原则**：UI 简约科幻 / 赛车赛道卡通化 / 特效克制，突出桌游策略感

---

## 一、全局视觉原则

### 1.1 核心设计理念

Foodula 1 本质上是一款**回合制策略卡牌游戏**，不是拟真赛车游戏。所有视觉决策必须服务于以下三条原则：

| 原则 | 说明 | 设计测试 |
|---|---|---|
| **信息优先** | 玩家每回合需要快速读懂：手牌、热量、档位、位置、弯道限速。花哨特效不能干扰决策信息 | "一个新手能否在 3 秒内理解当前局面？" |
| **风格二分** | UI 层 = 简约科幻；世界层（赛车/赛道）= 卡通美食。两层泾渭分明，互不污染 | "UI 面板和赛道画面放在一起，是否感觉来自两个不同游戏？→ 如果是，那正好。" |
| **桌游感** | 卡牌、回合、格子——这些是桌游的基因。视觉上要让人感觉到"这是一局精致的实体桌游被搬进了屏幕" | "截图放在桌游宣传页上，是否毫无违和感？" |

### 1.2 风格对照表

| 层级 | 风格 | 参考 | 关键词 |
|---|---|---|---|
| **UI / HUD** | 简约科幻 | F1 数字仪表盘 + 桌面卡牌游戏 UI 的混合 | 暗底、细线、冷光、无衬线字体 |
| **赛车模型** | 卡通化美食 | 《赛车总动员》的夸张比例 + 食物材质的可爱化处理 | 圆润、可辨识、食材纹理可见但不过真 |
| **赛道环境** | 卡通化实景 | 低多边形 + 柔和色调 + 各国地标剪影 | 轻松、有识别度、不喧宾夺主 |
| **卡牌** | 桌游质感 | 类似实体卡牌游戏的 UI 卡片——圆角、阴影、图标化 | 手牌可视化、数值大且清晰 |
| **特效** | **极简克制** | "少即是多"——没有粒子爆炸、屏幕震动、镜头炫光 | 仅保留：弯道判定提示、热量警告、尾流虚线、过线确认 |

## 二、UI 设计规范

### 2.1 整体布局

```
┌─────────────────────────────────────────────┐
│  TOP BAR：圈数 / 名次 / 天气图标              │
├────────────────────┬────────────────────────┤
│                    │                        │
│    赛道主视图       │   右侧面板             │
│    (占 70%)        │   档位指示器            │
│                    │   热量温度计            │
│                    │   车手头像+技能         │
│                    │                        │
├────────────────────┴────────────────────────┤
│  BOTTOM BAR：手牌区 (7 张牌，居中排列)        │
│  每张牌：大号数值 + 类型图标 + 高亮选中态      │
└─────────────────────────────────────────────┘
```

### 2.2 UI 色彩体系

| 用途 | 色值 | 说明 |
|---|---|---|
| 主背景 | `#0D1117`（深空黑） | UI 面板底色 |
| 面板底色 | `#161B22`（深灰蓝） | 信息卡片背景 |
| 主文字 | `#E6EDF3`（月白） | 所有主要文字 |
| 强调色 | `#58A6FF`（科技蓝） | 按钮、选中态、当前回合指示 |
| 热量/警告 | `#F78166`（警示橙） | 热量条、过热警告 |
| 成功/安全 | `#3FB950`（安全绿） | 冷却完成、安全通过弯道 |
| 分隔线 | `#30363D`（暗灰） | 面板边界，不抢眼 |

### 2.3 UI 组件风格指南

| 组件 | 设计 | 说明 |
|---|---|---|
| **档位指示器** | 圆形旋钮风格——类似炉灶旋钮的扁平化版本。1-4 档以弧形排列，当前档位亮科技蓝 | 世界观锚点：烹饪 → 灶台旋钮 |
| **热量温度计** | 垂直柱状条，从底部蓝色（冷）渐变至顶部红色（过热）。50%/70% 处有刻度线和警告色切换 | 必须一眼看清热量占比 |
| **手牌区** | 7 张卡牌扇形排列在底部。未选中牌轻微缩小并上浮；选中牌放大并下沉，显示数值动画 | 桌游"手中持牌"的直觉感 |
| **按钮** | 细边框 + 圆角矩形 + 图标 + 文字。悬浮态边框变亮，点击态填充。无渐变、无阴影 | 极简 UI 美学 |
| **字体** | 中文：思源黑体 Medium；英文/数字：Inter / JetBrains Mono（等宽数字） | 数字必须等宽，避免 UI 抖动 |

### 2.4 HUD 在赛道上的叠加

- 每辆赛车上方显示：**车队国旗图标 + 车手头像（小）+ 名次数字**
- 当前玩家赛车上方有**额外的边框高亮**（科技蓝脉冲光环）
- 弯道格子上方悬浮显示：限速数字（大号，清晰可读）
- 尾流触发时：前车与后车之间出现**虚线气流箭头**（科技蓝，持续 1 秒后消失）
- 绝不出现：赛车尾焰、路面粒子、镜头光晕、速度线

## 三、赛车视觉规范

### 3.1 整体风格

卡通化的核心是 **"食材的可读性 + 赛车的功能性"**——每个赛车必须让玩家在缩小视图下（赛道缩略图尺幅）也能一眼认出是什么食物、属于哪个国家。比例允许适度夸张（如 US 汉堡车的肉饼可以比正常比例大 1.5 倍），但不至于变成橡皮卡通。

**建模参考线：**
- 多边形面数：单辆赛车 ~2000-4000 tri（手机端优化）
- 贴图风格：手绘质感（Hand-Painted），非 PBR 写实
- 夸张度：类似《赛车总动员》的写实卡通（70% 真实比例 + 30% 夸张）

### 3.2 六支车队视觉卡

---

#### 🇬🇧 英国 — 炸鱼薯条赛车

| 元素 | 设计 |
|---|---|
| **主色** | 深海军蓝 + 金徽章——英伦经典 |
| **赛车造型** | 车身主体为**炸鱼排**——长条形、金黄面包糠外壳、鱼尾纹理可见。车头微微上扬（鱼头造型）。尾翼是**薯条格栅**——4-5 根粗薯条横排。排气管：**麦芽醋瓶**，倾斜安装 |
| **轮毂** | 柠檬片切片造型（英国炸鱼必备） |
| **卡通化处理** | 面包糠颗粒适当放大且排列规律（不要太密），鱼眼在车头大灯位置简化为一对圆灯 |
| **赛道识别度** | 金黄 + 蓝色组合在赛道上非常醒目 |
| **过热表现** | 鱼排从金黄 → 出现焦斑 → 薯条尖端变黑 |

| 元素 | 设计 |
|---|---|

#### 🇮🇹 意大利 — 意面披萨赛车

| 元素 | 设计 |
|---|---|

### 3.3 赛车尺寸与比例

所有赛车在赛道上占据 **1 格**。赛道格子的视觉尺寸应能容纳所有赛车并留有间隙。

| 参数 | 值 |
|---|---|
| 赛车基准长度 | 占据赛道格子的 80% |
| 赛车基准宽度 | 占据赛道格子的 60%（单车道） |
| 最宽赛车 | 美国汉堡车（宽度 = 80% 格子） |
| 最窄赛车 | 中国电动点心车（宽度 = 50% 格子） |

## 四、赛道视觉规范

### 4.1 整体风格

- **低多边形写实卡通**：赛道环境用简洁的几何体块构建，色调柔和
- **地标剪影**：每个赛道远景中有 1-2 个该国的标志性建筑剪影（不抢眼，但能立刻让人识别出"这是哪个国家"）
- **赛道本身是清晰的**：格子的边界线以浅色虚线标示（仅在缩放时可见，正常视距下融合），弯道格子有颜色编码（绿色 Lv1 → 黄色 Lv2 → 红色 Lv3）
- **观众**：简单的卡通小人（各国服饰差异），远景点缀而非焦点

### 4.3 天气系统（基于真实气候数据）

#### 天气类型定义

根据每条赛道所在地区的真实气候特征，定义五种天气类型：

| 天气 | 图标 | 游戏效果 | 触发条件说明 |
|---|---|---|---|
| ☀️ **晴天** | 太阳 | 无效果（基准状态） | 晴朗干燥，理想比赛条件 |
| ⛅ **多云** | 云 | 尾流效率 -1 | 空气密度变化，气流组织不稳定 |
| 🌧️ **小雨** | 雨滴 | 所有弯道限速 **-1**；打转后额外 **+1 热量** | 路面潮湿，抓地力下降。典型英式细雨 / 日本春雨 |
| ⛈️ **大雨** | 暴雨 | 所有弯道限速 **-2**；打转后额外 **+2 热量**；**尾流禁用**（水雾遮挡视线） | 暴雨/雷暴/台风。路面积水，水雾严重影响视野 |
| 🔥 **高温** | 温度计 | 冷却效率 **-1**（引擎更难散热） | 极端炎热天气，赛道温度 > 40°C |

## 五、卡牌视觉设计

卡牌是玩家每回合的核心交互对象，必须清晰直观。

### 5.1 卡牌布局

```
┌──────────────┐
│  🏎️          │  ← 卡牌类型图标（小，左上角）
│              │
│     3        │  ← 数值（居中，特大号）
│              │
│  速度牌      │  ← 卡牌名称（底部居中，小号）
└──────────────┘
```

### 5.2 卡牌类型外观

| 卡牌类型 | 边框色 | 底纹 | 数值显示 |
|---|---|---|---|
| **速度牌 1-4** | 科技蓝 `#58A6FF` | 极浅灰底 + 细条纹 | 大号数字 1/2/3/4 |
| **热量牌 0** | 警示橙 `#F78166` | 暖橙渐变底 + 火焰简化图标 | 大号 **0** |
| **压力牌** | 紫色 `#BC8CFF` | 紫色渐变底 + 问号图标 | 打出前显示 **?**，打出后揭示 1-4 |
| **升级牌** | 金色 `#D29922` | 金色渐变底 + 星形图标 | 0-3 + 特殊效果文字 |
| **秘方牌（日本专属）** | 朱红 `#E60012` + 金色边框 | 红色底 + 膳台纹理 | 按具体牌面显示 |

### 5.3 卡牌物理感

虽然是数字 UI，但卡牌应该保留 **"这是一张实体卡"** 的触感：
- 轻微圆角（半径 8px）
- 极细的边框（1px）
- 悬浮时有微小投影（offset 2px, blur 4px, opacity 20%）
- 选中时轻微放大（scale 1.05）+ 投影加深
- 打出时有一个简短的"卡牌飞出"过渡动画（0.3 秒，缓入缓出）

## 六、特效规范（极简克制）

### 6.1 允许的特效（完整列表）

| 特效 | 触发条件 | 视觉表现 | 持续时间 |
|---|---|---|---|
| **弯道判定** | 经过弯道格子 | 弯道限速数字轻微脉冲一次 | 0.3 秒 |
| **超速警告** | 超速产热时 | 屏幕边缘出现橙色微光（不遮挡文字） | 1 秒 |
| **过热警告** | 热量 ≥ 50% | 热量温度计从橙色变为红色闪烁 | 持续至冷却 |
| **冷却** | 降档冷却 | 热量温度计下降时有简短的蓝色光点从顶部飘出 | 0.5 秒 |
| **尾流虚线** | 触发尾流 | 后车与前车之间出现科技蓝虚线箭头 | 1 秒 |
| **过线** | 通过起点/终点 | 圈数数字放大并闪绿色 | 0.5 秒 |
| **打转** | 触发打转 | 赛车原地旋转 360° 的简短动画 | 1 秒 |
| **赛车移动** | 每回合移动 | 赛车沿格子弹跳移动（非平滑滑动——强调"格子"概念） | 每格 0.15 秒 |

### 6.2 明确禁止的特效

| 禁止项 | 原因 |
|---|---|
| 粒子爆炸 / 火花 / 火焰 | 不是动作游戏，分散注意力 |
| 屏幕震动（Screen Shake） | 干扰 UI 可读性 |
| 镜头光晕（Lens Flare） | 不是拟真赛车，不需要 |
| 速度线（Speed Lines） | 棋盘格移动，不需要速度感错觉 |
| 赛车尾焰 / 排气管火焰 | 同上 |
| 全屏过渡动画（闪白/闪黑） | 破坏回合节奏，用简单淡入淡出（0.3 秒）替代 |
