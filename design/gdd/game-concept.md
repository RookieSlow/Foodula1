## 1. 概述

Foodula1 MVP 是一个单人、单场次的卡牌驱动策略竞速游戏，改编自 HEAT 桌游的核心循环。
玩家在一条简化赛道上管理档位选择、出牌和热量积累，完成 3 圈比赛并与一个 AI 对手竞速。
本 MVP 的目标是验证 HEAT 核心机制（档位驱动出牌 + 热量牌循环 + 按弯道段判定）是否好玩，
然后再叠加上车队、车手、天气和多人模式。

**这是什么**: 最小可玩版本，回答"核心循环能跑通吗？"
**这不是什么**: 商业产品。完整愿景见 foodula-1-concept.md。

> **当前实现边界**：运行时已提供 8 条官方可选 JSON 赛道，另有
> `fallback_42` 作为无配置时的 42 节点回退；默认比赛仍为玩家对一名 AI，
> 但配置层支持更多对手。本文的“单条简化赛道”是 MVP 设计目标，不是当前
> 可选赛道数量的陈述。

## 2. 玩家体验（Player Fantasy）

玩家扮演一位策略型车手，在每个弯道前做出风险决策。每回合都是一次档位选择——
挂 4 档全力冲刺能拉开距离，但支付热量后会让热量牌堵塞手牌；降档可以冷却热量，但会被 AI 甩开。
赛道的弯道是紧张感的核心来源：超过弯道限速会产生热量牌，拖累后续回合的表现。
核心体验是**有计算的激进**——知道什么时候该冲，什么时候该收。

## 3. 详细规则

### 3.1 赛道
- MVP 设计目标是一条约 35-45 节点的简化闭合环线；当前实现的 MVP 回退赛道为
  `fallback_42`，实际可选赛道以 `Assets/Resources/Configs/Tracks/*.json` 为准
- 4-5 个命名弯道，每个弯道占据 1-3 个连续节点，共享同一个 `cornerId`
- 每个弯道有限速值（2-4，数字越小弯越急）
- 直道默认限速：99（实际等于无限制）
- 3 圈比赛，在起点/终点线判定完赛

### 3.2 牌组与手牌
- 关闭特技牌时为 12 张普通初始牌组：速度牌（1×3、2×5、3×3、4×1）；启用特技牌时为 16 张
- 热量牌不属于普通牌组；它只会在支付热量或明确技能效果时从独立引擎池进入手牌/弃牌堆
- 手牌上限：7 张。每回合开始补至 7 张
- 牌组抽空时：只将非热量弃牌洗入形成新牌组，热量牌留在原区域等待冷却
- 速度牌打出 = 移动对应格数。**热量牌不可打出**——它们占据手牌位，堵塞出牌空间
- 标准档位冷却在步骤 5「反应」阶段执行（G1=3、G2=1），按手牌→抽牌堆→弃牌堆；普通抽牌不会抽取热量牌
  顺序移除热量并归还引擎；明确写明“从手牌”效果（如中国 Recover）仍为手牌限定

### 3.3 档位系统
- 4 个档位（1-4）。档位决定该回合必须打出几张速度牌
- 1 档：打 1 张速度牌，冷却 3。2 档：打 2 张，冷却 1。3-4 档：无冷却
- 升档：±1 档免费，±2 档需支付 1 热力。每回合最多变 2 档
- 降档：规则同升档，±1 免费，±2 支付 1 热力

### 3.4 回合流程（9 步）
1. **换档** — ±1 档免费，±2 档支付 1 热力。每回合最多变 2 档。
2. **抽牌** — 从普通牌组抽速度/特技牌至手牌满 7 张，热量牌不参与
3. **出牌** — 选择等于当前档位数量的速度牌。热量牌不可选出。速度牌不足时触发引擎故障
4. **移动** — 按打出的速度牌数值之和前进
5. **反应** — 根据档位冷却：G1 冷却 3，G2 冷却 1。标准冷却按手牌→抽牌堆→弃牌堆
   移除热量牌归还引擎
6. **弯道判定**（弯心判定） — 踩到弯心时：总移动力 > 限速 → 从引擎支付差额热量入手牌（明确效果可指定弃牌堆）
7. **尾流** — MVP 暂不做
8. **弃牌** — 可选弃掉手中任意非热量牌
9. **收尾** — 打出的速度牌 → 弃牌堆。补普通牌至 7 张。

### 3.5 热量系统

**热量牌生命周期（HEAT 原版规则）：**

```
引擎牌库（每玩家独立）
    │
    │ 支付热量 / 明确技能效果
    ├────────────────→ 手牌或弃牌堆
    │                    │
    │                    │ 不参与普通抽牌
    │                    │
    │                    │ 档位冷却（G1=3, G2=1, 步骤 5 反应阶段）
    │                    ↓
    └────────────── 引擎牌库（回到起点）

普通牌组只包含速度牌和特技牌；开局与回合补牌不会抽到热量牌。
```

**三条硬规则：**
1. **热量牌不可打出**（作为正常出牌）— 它占据手牌位置，限制可用速度牌数量
2. **热量牌不可主动弃置** — 弃牌步骤不能选择热量牌
3. **热量牌不参与普通抽牌** — 只会在支付热量或明确技能效果时进入手牌/弃牌堆
4. **标准档位冷却是自动移除热量牌的主要途径** — 步骤 5「反应」阶段 G1 冷却 3、G2 冷却 1，按手牌→抽牌堆→弃牌堆；明确“从手牌”的效果仍手牌限定

- **每个玩家拥有独立的引擎牌库**（每玩家 6 张热量牌）
- 弯道超速 → 从引擎牌库支付 `(超速值)` 张热量牌 → 默认进入手牌
- 引擎故障（速度牌不够）→ 每缺 1 张从引擎牌库支付 1 张热量牌 → 默认进入手牌
- ±2 换档 → 支付 1 张热力牌进入手牌；明确效果（如阴阳茶 Go）可指定弃牌堆
- 牌组抽空时 → 只将非热量弃牌洗入牌组 → 继续抽普通牌
- 牌组 + 弃牌堆为空时不影响比赛，仅无法补满手牌，可继续以少量手牌参赛

### 3.6 失控与退赛

**触发失控：** 任何需要从引擎牌库支付热量但引擎已空时。

| 触发场景 | 说明 |
|------|------|
| 弯心超速 | 总速度 > 弯道限速，引擎不够付差额 |
| 引擎故障 | 速度牌不够档位，引擎不够付缺额 |
| ±2 换档 | 支付 1 热力，引擎不够 → 失控 |

**失控处理流程：**

```
1. 退赛计数器 +1（显示 ⚠ ×N/3）
2. 回退位置：弯心超速 → 弯心前一格；引擎故障/±2换档 → 原地
3. 回收全部热量牌 → 引擎牌库（重新点火）
   · 手牌和弃牌堆中的所有热量牌 → 移除 → 归还引擎（牌组仅兼容旧状态）
4. 强制降至 1 档
5. 跳过下一回合（引擎已在恢复时满额，无需额外冷却）
```

**退赛淘汰：** 退赛计数器累计满 3 次 → 赛车报废，直接淘汰。

### 3.6 胜负条件
- **胜利**: 最终排名第 1；率先完成最后一圈的赛车锁定领先名次
- **失败**: 玩家爆缸或最终排名未达到第 1 名。玩家爆缸只淘汰玩家赛车，
  不立即终止其他非爆缸赛车的结算。
- **比赛结束**: 任意赛车完成最后一圈后，继续结算所有仍在比赛中的非爆缸赛车；
  所有非爆缸赛车完成或没有仍在比赛中的赛车后结束。
- 完赛排名：按圈数排序，同圈按赛道位置排序

### 3.7 AI 对手
- 简单行为树，4 个优先级节点（来自 foodula-1-ai.md）；当前默认一名 AI，
  配置层可扩展到更多对手：
  - P1（生存检查）：热量 ≥ 70% → 降到 1 档全力冷却；手牌不足 → 降档
  - P2（弯道策略）：预判前方弯道限速 → 选择档位/出牌保持在限速内
  - P3（尾流）：MVP 不做
  - P4（常规推进）：热量低 → 升档冲刺；正常 → 保持档位 + 随机变化
- AI 使用简单难度：保守热量管理，在约束范围内随机选牌

## 4. 公式

| 公式 | 定义 | 变量 |
|------|------|------|
| 移动距离 | `sum(已打速度牌数值)` | 速度牌 1-4 |
| 弯道惩罚 | 对每个穿过的 unique `cornerId`: `max(0, 移动距离 - 弯道限速)` 张热量牌 → 弃牌堆 | 移动距离: 本回合总步数; 弯道限速: 2-4 |
| 热量支付 | 从玩家引擎牌库支付 N 张热量牌，默认进入手牌；明确效果可指定弃牌堆 | N = 弯道超速值 / 引擎故障缺额 / ±2换档(1) |
| 档位冷却 | G1 = 冷却 3, G2 = 冷却 1 | 步骤 5 反应阶段执行 |
| 失控 | 引擎不足以支付所需热量 → 计数器+1, 全热量回收, 回退位置, 强制1档, 跳过下回合 | 计数器=3 → 退赛 |
| 补牌 | 抽牌至 hand.size == 7。牌组空 → 洗入弃牌堆形成新牌组 | 手牌上限 = 7 |
| 圈数计算 | 通过起点/终点线时圈数 +1。完成最后一圈的赛车锁定顺位；所有非爆缸赛车完成或无活动赛车后比赛结束 | |
| 退赛淘汰 | 失控计数器累计满 3 次 → 淘汰 | |

## 5. 边界情况

- **弯心判定**: 每个弯道只有一个弯心节点。只有移动路径踩到弯心才触发判定
- **一次移动穿过多个弯心**: 如果移动踩到两个不同 cornerId 的弯心，各自独立判定，惩罚求和
- **精确匹配**: 移动距离 == 弯道限速 → 零惩罚
- **失控不淘汰**: 第 1-2 次失控恢复后可继续比赛，第 3 次才退赛
- **失控回收热量**: 手牌/弃牌堆中所有热量牌回到引擎，引擎重新满额（牌组扫描仅兼容旧状态）
- **跳过回合**: 失控后跳过下一回合（引擎已在恢复时满额，无需冷却）
- **引擎牌库不足**: 引擎不足以支付热量需求 → 立即触发失控
- **空牌组 + 空弃牌堆**: 不影响继续比赛，仅无法补满手牌
- **全热手牌**: 强制降至 1 档，利用 G1 冷却 3 逐步清除热量
- **圈数计数**: 仅正向通过终点线时触发，倒车不算
