## 1. 概述

Foodular1 MVP 是一个单人、单场次的卡牌驱动策略竞速游戏，改编自 HEAT 桌游的核心循环。
玩家在一条简化赛道上管理档位选择、出牌和热量积累，完成 3 圈比赛并与一个 AI 对手竞速。
本 MVP 的目标是验证 HEAT 核心机制（档位驱动出牌 + 热量牌循环 + 按弯道段判定）是否好玩，
然后再叠加上车队、车手、天气和多人模式。

**这是什么**: 最小可玩版本，回答"核心循环能跑通吗？"
**这不是什么**: 商业产品。完整愿景见 foodula-1-concept.md。

## 2. 玩家体验（Player Fantasy）

玩家扮演一位策略型车手，在每个弯道前做出风险决策。每回合都是一次档位选择——
挂 4 档全力冲刺能拉开距离，但会抽到热量牌堵塞手牌；降档可以冷却热量，但会被 AI 甩开。
赛道的弯道是紧张感的核心来源：超过弯道限速会产生热量牌，拖累后续回合的表现。
核心体验是**有计算的激进**——知道什么时候该冲，什么时候该收。

## 3. 详细规则

### 3.1 赛道
- 一条简化赛道，约 35-45 个节点，闭合环线
- 4-5 个命名弯道，每个弯道占据 1-3 个连续节点，共享同一个 `cornerId`
- 每个弯道有限速值（2-4，数字越小弯越急）
- 直道默认限速：99（实际等于无限制）
- 3 圈比赛，在起点/终点线判定完赛

### 3.2 牌组与手牌
- 15 张初始牌组：12 张速度牌（1×3、2×5、3×3、4×1）+ 3 张热量牌（值为 0）
- 手牌上限：7 张。每回合开始补至 7 张
- 牌组抽空时：将弃牌堆洗入形成新牌组
- 速度牌打出 = 移动对应格数。**热量牌不可打出**——它们占据手牌位，堵塞出牌空间
- 热量牌只能通过步骤 5「反应」阶段的档位冷却（G1=3, G2=1）从手牌中移除，回到该玩家的引擎牌库

### 3.3 档位系统
- 4 个档位（1-4）。档位决定该回合必须打出几张速度牌
- 1 档：打 1 张速度牌，冷却 3。2 档：打 2 张，冷却 1。3-4 档：无冷却
- 升档：±1 档免费，±2 档需支付 1 热力。每回合最多变 2 档
- 降档：规则同升档，±1 免费，±2 支付 1 热力

### 3.4 回合流程（9 步）
1. **换档** — ±1 档免费，±2 档支付 1 热力。每回合最多变 2 档。
2. **抽牌** — 从牌组抽牌至手牌满 7 张
3. **出牌** — 选择等于当前档位数量的速度牌。热量牌不可选出。速度牌不足时触发引擎故障
4. **移动** — 按打出的速度牌数值之和前进
5. **反应** — 根据档位冷却：G1 冷却 3，G2 冷却 1。从手牌移除热量牌归还引擎
6. **弯道判定**（弯心判定） — 踩到弯心时：总移动力 > 限速 → 从引擎抽差额热量入弃牌堆
7. **尾流** — MVP 暂不做
8. **弃牌** — 可选弃掉手中任意非热量牌
9. **收尾** — 打出的速度牌 → 弃牌堆。补牌至 7 张。

### 3.5 热量系统

**热量牌生命周期（HEAT 原版规则）：**

```
引擎牌库（每玩家独立）
    │
    │ 弯道超速 / 引擎故障 → 从引擎支付热量牌
    ↓
弃牌堆
    │
    │ 牌组抽空 → 洗入弃牌堆（含热量牌）
    ↓
牌组 → 抽牌 → 手牌
    │
    │ 热量牌不可打出、不可主动弃置。纯粹占手牌位。
    │
    │ 档位冷却（G1=3, G2=1, 步骤 5 反应阶段）
    ↓
引擎牌库（回到起点）
```

**三条硬规则：**
1. **热量牌不可打出**（作为正常出牌）— 它占据手牌位置，限制可用速度牌数量
2. **热量牌不可主动弃置** — 弃牌步骤不能选择热量牌
3. **档位冷却是唯一从手牌移除热量牌的途径** — 步骤 5「反应」阶段：G1 冷却 3，G2 冷却 1，G3/G4 无冷却

- **每个玩家拥有独立的引擎牌库**（每玩家 6 张热量牌）
- 弯道超速 → 从引擎牌库抽取 `(超速值)` 张热量牌 → 放入弃牌堆
- 引擎故障（速度牌不够）→ 每缺 1 张从引擎牌库抽 1 张热量牌 → 放入弃牌堆
- ±2 换档 → 支付 1 张热力牌至弃牌堆
- 牌组抽空时 → 弃牌堆（含热量牌）洗入牌组 → 继续抽牌
- 牌组 + 弃牌堆为空时不影响比赛，仅无法补满手牌，可继续以少量手牌参赛

### 3.6 失控与退赛

**触发失控：** 任何需要从引擎牌库支付热量但引擎已空时。

| 触发场景 | 说明 |
|------|------|
| 弯心超速 | 总速度 > 弯道限速，引擎不够付差额 |
| 引擎故障 | 速度牌不够档位，引擎不够付缺额 |
| ±2 换档 | 支付 1 热力，引擎不够 → 失控 |

**失控处理流程：**

```
1. 退赛计数器 +1（显示 ⚠ ×N/3）
2. 回退位置：弯心超速 → 弯心前一格；引擎故障/±2换档 → 原地
3. 回收全部热量牌 → 引擎牌库（重新点火）
   · 手牌、牌组、弃牌堆中的所有热量牌 → 移除 → 归还引擎
4. 强制降至 1 档
5. 跳过下一回合（引擎已在恢复时满额，无需额外冷却）
```

**退赛淘汰：** 退赛计数器累计满 3 次 → 赛车报废，直接淘汰。

### 3.6 胜负条件
- **胜利**: 完成 3 圈后率先通过终点线
- **失败**: AI 率先完成 3 圈，或玩家失控 3 次退赛
- 完赛排名：按圈数排序，同圈按赛道位置排序

### 3.7 AI 对手
- 简单行为树，4 个优先级节点（来自 foodula-1-ai.md）：
  - P1（生存检查）：热量 ≥ 70% → 降到 1 档全力冷却；手牌不足 → 降档
  - P2（弯道策略）：预判前方弯道限速 → 选择档位/出牌保持在限速内
  - P3（尾流）：MVP 不做
  - P4（常规推进）：热量低 → 升档冲刺；正常 → 保持档位 + 随机变化
- AI 使用简单难度：保守热量管理，在约束范围内随机选牌

## 4. 公式

| 公式 | 定义 | 变量 |
|------|------|------|
| 移动距离 | `sum(已打速度牌数值)` | 速度牌 1-4 |
| 弯道惩罚 | 对每个穿过的 unique `cornerId`: `max(0, 移动距离 - 弯道限速)` 张热量牌 → 弃牌堆 | 移动距离: 本回合总步数; 弯道限速: 2-4 |
| 热量抽取 | 从玩家引擎牌库抽 N 张热量牌，放入弃牌堆 | N = 弯道超速值 / 引擎故障缺额 / ±2换档(1) |
| 档位冷却 | G1 = 冷却 3, G2 = 冷却 1 | 步骤 5 反应阶段执行 |
| 失控 | 引擎不足以支付所需热量 → 计数器+1, 全热量回收, 回退位置, 强制1档, 跳过下回合 | 计数器=3 → 退赛 |
| 补牌 | 抽牌至 hand.size == 7。牌组空 → 洗入弃牌堆形成新牌组 | 手牌上限 = 7 |
| 圈数计算 | 通过起点/终点线时圈数 +1。第 3 圈通过 → 比赛结束 | |
| 退赛淘汰 | 失控计数器累计满 3 次 → 淘汰 | |

## 5. 边界情况

- **弯心判定**: 每个弯道只有一个弯心节点。只有移动路径踩到弯心才触发判定
- **一次移动穿过多个弯心**: 如果移动踩到两个不同 cornerId 的弯心，各自独立判定，惩罚求和
- **精确匹配**: 移动距离 == 弯道限速 → 零惩罚
- **失控不淘汰**: 第 1-2 次失控恢复后可继续比赛，第 3 次才退赛
- **失控回收热量**: 手牌/牌组/弃牌堆中所有热量牌回到引擎，引擎重新满额
- **跳过回合**: 失控后跳过下一回合（引擎已在恢复时满额，无需冷却）
- **引擎牌库不足**: 引擎不足以支付热量需求 → 立即触发失控
- **空牌组 + 空弃牌堆**: 不影响继续比赛，仅无法补满手牌
- **全热手牌**: 强制降至 1 档，利用 G1 冷却 3 逐步清除热量
- **圈数计数**: 仅正向通过终点线时触发，倒车不算

## 7. 可调参数

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| 赛道节点数 | 35-45 | 20-60 | 越少 = 比赛越快 |
| 弯道数量 | 4-5 | 3-8 | 越多 = 热量压力越大 |
| 弯道限速 | 2-4 | 2-4 | 数字越小弯越急。MVP 最低为 2 |
| 手牌上限 | 7 | 5-9 | 影响策略深度 |
| 牌组构成 | 12 速度 + 3 热量 | 可变 | 影响热量压力 |
| 热量池大小 | 6（单人） | 4-12 | 越小越危险 |
| 圈数 | 3 | 1-5 | HEAT 标准比赛长度 |
| AI 难度 | 简单 | 简单/中等/困难 | 保守热量管理 |

## 8. 验收标准

- [ ] 玩家可以在回合开始时切换档位（1-4）
- [ ] 步骤 5 反应阶段根据档位执行冷却（G1=3, G2=1）
- [ ] 每回合开始自动补牌至 7 张
- [ ] 牌组循环正常：牌组空 → 洗入弃牌堆 → 继续抽牌
- [ ] 打出速度牌使卡车按数值之和移动
- [ ] 热量牌不可选中/不可打出，始终留在手牌中
- [ ] 弯心判定：仅踩到弯心节点时触发，分两次过弯不重复判定
- [ ] 弯道惩罚从玩家引擎牌库抽取正确数量的热量牌放入弃牌堆
- [ ] 通过起点/终点线时圈数递增
- [ ] 3 圈后比赛结束，显示完赛排名（玩家 vs AI）
- [ ] AI 使用 4 优先级行为树选择档位和出牌
- [ ] 失控：引擎不足支付时触发，计数器+1，回收热量，回退，跳过回合
- [ ] 退赛：失控计数器=3 时淘汰
- [ ] 重置按钮恢复完整比赛状态
- [ ] 所有游戏数值通过 ScriptableObject 配置
