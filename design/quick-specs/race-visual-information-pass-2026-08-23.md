# 比赛视觉信息与反馈强化

**日期：** 2026-08-23
**分类：** Addition
**状态：** P0 与 P1 卡牌选中态/牌堆预览已实现；Play Mode walkthrough pending

## 背景

当前比赛核心规则已经基本接入，但几个关键状态主要依赖文字或调试覆盖层表达：

1. 卡牌选中态只有颜色遮罩，没有位置和层级反馈。
2. 挡位缺牌惩罚已经存在，但玩家在结束出牌前不容易预判后果。
3. 抽牌堆和弃牌堆只显示数量，无法直观看到实际卡牌。
4. 运行时赛道隐藏普通格编号，玩家位置主要依赖 HUD 文字。
5. 尾流规则已经生效，但没有独立的视觉演出阶段。

本提案只强化信息表达和演出，不改变热量、挡位、移动或尾流的核心结算规则。

## 优先级与工作包

### P0：核心规则可见性（已实现）

**挡位要求与引擎故障预警**

- 使用本回合有效出牌上限，而不是只显示原始档位数值。
- 显示“已出 X / 要求 Y”。
- 缺少速度牌时，结束出牌按钮附近显示“缺 N 张：引擎故障，增加 N 热量”。
- 若引擎热量不足，提示可能触发失控。
- 中国队 Go/Recover、火锅额外牌位等特殊规则继续使用各自的有效要求值。

### P1：基础交互与状态可读性

**选中卡牌高亮**

**实现状态：已实现（EditMode 396/396；Play Mode 遮罩边界待走查）**

- 卡牌布局槽位保持不变。
- 选中卡牌缩放到 1.05–1.10 倍，并向上移动 18–28px。
- 增加阴影和现有绿色选中遮罩。
- 使用约 0.12–0.18 秒的缓动过渡。
- 必须避免被手牌区的 RectMask2D 裁切，也不能挤动相邻卡牌。

**抽牌堆与弃牌堆缩略卡牌**

**实现状态：已实现（EditMode 396/396；Play Mode 尺寸与可读性待走查）**

- 以牌背叠放表达牌堆，而不是只显示文字。
- 显示顶部 1–3 张实际卡牌的缩略面。
- 右下角保留牌堆数量徽标。
- 抽牌堆、弃牌堆在抽牌、出牌、弃牌、冷却和进站后刷新。
- 热量牌按其真实所在区域显示；普通抽牌仍不会主动抽取热量牌。
- 初版不增加点击查看牌堆内容的交互，避免扩大范围。

**2026-08-25 增量实现：区域流转与牌堆厚度**

- 牌堆从固定两层牌背改为数量驱动：每 3 张增加一层，最多 7 层，数量徽标仍精确。
- 速度牌收尾、特技牌确认和主动弃牌播放手牌→弃牌堆动画。
- 热量支付播放引擎→手牌/弃牌堆动画；冷却按真实来源播放手牌/抽牌堆/弃牌堆→引擎动画。
- 默认 0.32 秒、0.045 秒批量错峰、最多 6 个视觉实例，使用未缩放时间且不阻塞规则。
- 代码与纯表现规则回归已完成；Play Mode 动画遮罩、节奏和层距待人工走查。

**赛道格数与玩家位置**

- 继续使用赛道 JSON 中的节点坐标，不先重绘完整赛道背景。
- 玩家界面统一使用 1-based 的“格 X/N”。
- 当前赛车增加明显的蓝色光环或边框。
- 在玩家附近显示前后 5–7 格的局部刻度尺和格号。
- F8 调试覆盖层继续保留 0-based 编号，用于开发者校准。
- 长赛道和高密度赛道使用自适应字号、间隔或抽样显示，避免文字重叠。

### P2：演出增强

**尾流独立显示阶段**

> 实施状态（2026-08-24）：代码与 EditMode 回归已完成（405/405）；待包含真实尾流触发的
> Play Mode 人工画面走查。

- 尾流结算层记录前车、后车和最终加成。
- 仅在尾流加成大于 0 时播放。
- 播放 0.8–1.0 秒的蓝色虚线气流、两车短暂聚焦和“尾流 +N”提示。
- 多个同时发生的尾流可以合并为一次阶段，避免阻塞回合。
- 特写自身使用不受 `Time.timeScale` 影响的演出计时，但 `0.28` 倍慢放作用域会继续覆盖

  速度牌移动和后续回合。
- 初版可使用 LineRenderer 或 UI 线条，后续再替换为专用尾流贴图。

## 验收标准

- 选中卡牌在多选速度牌和单张特技牌两种模式下都能放大上移，且不裁切、不改变布局。
- 缺牌数量与规则层计算完全一致；未补足时仍按既有引擎故障路径结算。
- 抽牌堆和弃牌堆显示实际卡牌缩略图、牌背叠放和正确数量，并在所有牌堆变化后刷新。
- 所有官方赛道和 fallback 赛道都能显示正确的当前格、总格数和当前车辆标记。
- 尾流只在实际获得加成时播放一次，不重复加成、不阻塞后续移动。
- 相关 EditMode 测试通过，并完成至少一局 Play Mode 人工验证。
