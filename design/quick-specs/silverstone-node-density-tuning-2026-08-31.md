# Quick Design Spec: 银石赛道格子密度调优

**Type**: Tuning
**System**: Track Data / Track Presentation
**GDD Reference**: `design/gdd/foodula-1-tracks.md` — 2.1 银石下午茶赛道
**Date**: 2026-08-31

## Change

| Parameter | Old Value | New Value | Rationale |
|---|---|---|---|
| 银石节点空间采样 | 21–41 段存在约 3 世界单位的相邻跨度，局部格距可达起始段常规格距的 4–5 倍 | 按运行时 30×16.875 世界比例沿现有中心线重采样 60 个节点；21–41 段最大格距不超过全赛道中位数的 1.35 倍 | 消除视觉上“一格抵多格”的跳跃感，使车辆逐格移动速度和局部格号密度一致 |
| 弯道元数据位置 | 绑定旧的不均匀节点序号 | 迁移到重采样后对应的可见弯位 | 保持弯道遮罩、限速与背景道路对齐 |
| 直道层级 | 第一轮只把银石机库直道扩至 12 格，导致该段相对其他直道过密 | 按真实主直道/中距离直道/短连接段重新分配；银石形成 12/10/10/9/7 等层级，总格数 77 | 保留完整冲刺，同时避免只有一条直道异常密集 |

## Tuning Knob Mapping

对应赛道 GDD 的“比例缩放”和“保留弯道节奏”。最终版本按现实直道等级整体分配格数，并同步高速弯限速。圈数、实际里程、线路形状、弯道数量和赛事规则保持不变。

## Acceptance Criteria

- [ ] `silverstone_afternoon_tea` 为 77 格、3 圈、20 个弯道格和 13 个弯心。
- [ ] 银石机库直道为 12 格，惠灵顿与汉密尔顿直道各为 10 格，中距离直道按相对长度递减。
- [ ] 八张正式地图每张至少有一条连续 12 格的大直道，可容纳 4+3+3+2 的完整冲刺。
- [ ] 起终点节点 0 坐标保持不变，所有节点仍位于 `[0,1]` 归一化范围。
- [ ] 21–41 段最大相邻世界距离不超过全赛道中位相邻距离的 1.35 倍。
- [ ] 所有原有 corner ID、等级、限速和弯心数量保持不变，并落在相同可见弯位附近。
- [ ] Unity EditMode 回归通过；现实对照校准涉及六张标准赛道的直道比例及八图高速弯限速审计。
