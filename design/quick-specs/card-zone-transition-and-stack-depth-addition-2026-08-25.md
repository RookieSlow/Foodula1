# Quick Design Spec: 卡牌区域流转与牌堆厚度

**Type**: Addition
**System**: 比赛卡牌 UI / 牌堆反馈
**GDD Reference**: `design/gdd/foodula-1-visual-style.md`
**Date**: 2026-08-25

## Change Summary

为现有手牌、抽牌堆、弃牌堆和引擎库增加非阻塞卡牌流转动画，并让牌堆的可见
牌背层数随真实卡牌数量增长。玩法结算、卡牌区域所有权和热量规则不变。

## Motivation

当前牌堆已经能显示顶部实际卡牌和精确数量，但区域变化仍是瞬时刷新，玩家需要依赖
文字日志理解“卡去了哪里”。本改动用克制的实体牌飞行动画强化因果关系，并用厚度
提供无需阅读数字的数量级判断。

## Design Delta

当前 GDD 在“5.3 卡牌物理感”中要求：

> 打出时有一个简短的“卡牌飞出”过渡动画（0.3 秒，缓入缓出）

本规格将其落实为完整区域流转规则：

- 速度牌回合收尾、特技牌确认和主动弃牌时，从手牌区飞向弃牌堆。
- 标准热量支付从引擎库飞向手牌；明确的弃牌堆支付从引擎库飞向弃牌堆。
- 标准冷却按真实来源区域（手牌→抽牌堆→弃牌堆）飞回引擎库；手牌限定冷却只从
  手牌飞回引擎。
- 动画是表现层事件，不延迟、不重复也不回滚规则层结算。

## New Rules / Values

- 单张飞行时长：`0.32s`，使用 unscaled time 和 SmoothStep 缓动。
- 轨迹：起终点之间增加 `76px` 的上拱弧线。
- 批量间隔：`0.045s`；单次最多创建 `6` 个视觉实例，超出部分在最后一张显示倍数。
- 牌堆厚度：每 `3` 张增加一层牌背，范围 `0–7` 层；数量徽标始终显示精确值。
- 使用现有速度牌、热量牌和数字精灵；资源缺失时使用现有科技蓝/热量橙纯色回退。

## Affected Systems

| System | Impact | Action Required |
|---|---|---|
| CardDeck | 仅暴露分区热量计数供表现层读取 | 不改区域规则 |
| MVPGameManager | 在既有支付、冷却、弃牌调用点发出视觉事件 | 保持原结算顺序 |
| CardHandUI | 解析四个已编排区域并持有运行时 Overlay | 不改场景资源 |
| CardPilePreviewUI | 数量驱动牌背层数 | 保留顶部卡与精确徽标 |

## Acceptance Criteria

- [x] 速度牌、特技牌和主动弃牌能触发手牌→弃牌堆动画。
- [x] 热量支付按真实目标触发引擎→手牌/弃牌堆动画。
- [x] 标准冷却按真实来源优先级触发来源→引擎动画；阴阳茶 Recover 保持手牌限定。
- [x] 牌堆厚度随数量增加并在 7 层封顶，精确数量徽标不变。
- [x] 视觉事件不等待协程完成，不改变卡牌和热量数值。
- [x] 针对性 EditMode 69/69、全量 EditMode 430/430 通过，Console 0 错误/警告。
- [ ] Play Mode 人工确认动画未被遮罩裁切、弧线方向自然且批量动画不显拥挤。
- [ ] Play Mode 人工确认所有牌堆变化结束后顶部缩略图和数量立即正确刷新。
