# Foodula1 交互模式

## 教程指引面板

- 右上角指引面板是教程章节浏览的唯一入口。真实比赛事件只把当前课程标记为“已完成”，不自动翻页。
- “下一步”仅在阅读步骤或当前操作已完成时可用；“上一步”只回看已到达的说明，不回滚牌区、车辆、天气或检查点。
- 回看期间暂停比赛输入；返回当前课程后继续原来的比赛状态。进入下一课程所需的脚本检查点只执行一次。
- 保留“跳过引导”和“退出教程”，避免手动翻页降低原有可达性。

## 操作聚光

- 聚光优先跟随当前真实输入门，而不是当前课程主题：换挡、选牌、确认出牌、结束出牌、选弃牌、确认弃牌、维修区选择和车道选择都必须有目标框。
- 操作变化时显示新的短说明。玩家任意独立单击后，短说明气泡完整清空并隐藏，但金色边框继续指示本次操作，不拦截鼠标。
- 进入下一种操作时重新显示对应短说明；同一操作的普通 UI 刷新不得复活已经关闭的文字。
- 开启“减少动态”时边框保持静态。颜色之外还必须使用位置、边框和文字共同表达目标。

## 主菜单覆盖层

- 自由赛事、车手选择、生涯、科技树、设置和百科为互斥覆盖层；打开一个入口前先关闭其他覆盖层。
- 当前覆盖层始终置于主菜单按钮之上。关闭后不恢复先前覆盖层，也不遗留确认文字或夏休科技面板。
