# Foodula1 交互模式

## 教程指引面板

- 右上角指引面板是教程章节浏览的唯一入口。真实比赛事件只把当前课程标记为“已完成”，不自动翻页。
- “下一步”仅在阅读步骤或当前操作已完成时可用；“上一步”只回看已到达的说明，不回滚牌区、车辆、天气或检查点。
- 回看期间暂停比赛输入；返回当前课程后继续原来的比赛状态。进入下一课程所需的脚本检查点只执行一次。
- 保留“跳过引导”和“退出教程”，避免手动翻页降低原有可达性。

## 操作聚光

- 聚光优先跟随当前真实输入门，而不是当前课程主题：换挡、选牌、确认出牌、结束出牌、选弃牌、确认弃牌、维修区选择和车道选择都必须有目标框。
- 操作变化时显示新的短说明。玩家任意独立单击后，短说明气泡完整清空并隐藏，但金色边框继续指示本次操作，不拦截鼠标。
- 进入下一种操作时重新显示对应短说明；同一操作的普通 UI 刷新不得复活已经关闭的文字。
- 开启“减少动态”时边框保持静态。颜色之外还必须使用位置、边框和文字共同表达目标。

## 主菜单覆盖层

- 自由赛事、车手选择、生涯、科技树、设置和百科为互斥覆盖层；打开一个入口前先关闭其他覆盖层。
- 当前覆盖层始终置于主菜单按钮之上。关闭后不恢复先前覆盖层，也不遗留确认文字或夏休科技面板。

## 比赛退出确认

- 比赛中的“返回主菜单”和完赛面板中的同名入口共用一个二次确认弹窗；首次点击只打开弹窗，不改变比赛状态。
- 弹窗使用全屏遮罩拦截底层比赛操作。“留在比赛”关闭弹窗并恢复输入；“返回主菜单”才执行主菜单场景切换。
- 弹窗文字明确说明当前比赛进度不会保存。旧版 RaceCanvas 缺少该面板时由 `HUDUI` 运行时补齐，不覆盖手动布局。

## 长演出跳过

- 基础移动、超车特写、尾流特写和尾流奖励移动期间，点击任意位置都请求跳过当前表现。
- 跳过只收束动画、缓冲和临时卡牌飞行；已确定的车辆位置、尾流加成、圈数、弯道、地标和维修区穿越仍按原流程结算。
- 必需的车道选择、维修区预选和教程翻页不被跳过。状态栏在可跳过窗口显示操作提示，避免增加额外的固定按钮遮挡赛道。

## 局内操作确认偏好

- 设置提供逐项开关：换挡选择、确认换挡、出牌/弃牌、车手技能、重新开始、返回主菜单、维修区决定、印地换道。
- 默认保护所有会立即改变比赛状态或离开当前比赛的提交操作；换挡选择默认不弹窗，因为它只是待提交选择，
  真正的档位锁定按钮仍有独立确认。玩家可以在设置中开启换挡选择，或关闭任意不需要的确认。
- 确认弹窗使用同一个全屏模态层，点击底层区域不会穿透；取消不改变比赛状态，确认才执行原回调。按钮文案按动作区分：换挡使用“返回修改 / 锁定档位”，返回主菜单使用“留在比赛 / 返回主菜单”，避免“继续比赛 / 确认返回”在不同动作中产生歧义。
- 卡牌只在“出牌/弃牌”提交按钮上确认，卡牌选中本身不确认；教程翻页、跳过/退出教程、关闭百科/限速明细
  等非比赛状态变更操作不确认。

## 弯道限速解释

- 弯心旁数字显示当前玩家视角的有效限速，而非脱离天气/技能/车队/科技的静态原值。
- 单击数字打开只读面板，按固定顺序显示：赛道原始限速、天气影响、车手技能影响、车队操控影响、科技树影响、
  当前有效限速。正向修正显示 `+N`，负向修正显示 `-N`。
- 面板不暂停或改变比赛；关闭后回到原比赛界面。天气免疫仍显示天气负修正，并在车手技能行显示补偿，
  让玩家能理解为什么最终限速没有下降。
